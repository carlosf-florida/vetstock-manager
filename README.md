# VetStock Manager

Aplicación web para gestionar stock, pedidos y autorizaciones de pedidos en una distribuidora de productos veterinarios.

## Objetivo principal

Centralizar el control de productos y stock, la creación de pedidos para veterinarios y el proceso de revisión y autorización antes del envío.

## Tecnologías previstas

- Java
- Spring Boot
- MySQL
- Git y GitHub
- Frontend pendiente de definir
