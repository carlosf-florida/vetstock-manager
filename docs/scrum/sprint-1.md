# Sprint 1 — VetStock Manager

## Duración

Dos semanas.

## Sprint Goal

Al finalizar el Sprint 1, el responsable de almacén podrá acceder a VetStock Manager, consultar productos con stock disponible, registrar veterinarios y crear un pedido básico asociado a un veterinario.

## Capacidad

14 Story Points.

## Historias seleccionadas

| ID | Historia | Puntos |
|---|---|---:|
| US-01 | Inicio de sesión para responsable de almacén | 3 |
| US-02 | Consulta de productos y stock disponible | 3 |
| US-03 | Registro de veterinarios | 3 |
| US-04 | Creación de pedido asociado a veterinario | 5 |
| **Total** |  | **14** |

## Tareas principales

- Crear la estructura inicial del proyecto y configurar MySQL.
- Crear entidades o tablas para Usuario, Veterinario, Producto y Pedido.
- Añadir datos de prueba.
- Implementar inicio de sesión básico.
- Crear el listado y buscador de productos.
- Crear formulario y validaciones de veterinarios.
- Crear formulario de pedido, seleccionar veterinario y guardar el pedido.
- Hacer pruebas manuales y actualizar el README.
