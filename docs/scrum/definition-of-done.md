# Definition of Done — VetStock Manager

Una historia de usuario se considera terminada cuando cumple todos estos criterios:

- [ ] La funcionalidad está implementada.
- [ ] La funcionalidad funciona correctamente en local.
- [ ] Se han comprobado los casos principales y los datos inválidos.
- [ ] El código está subido a GitHub.
- [ ] El código está integrado en la rama `main` sin conflictos.
- [ ] No hay errores críticos conocidos relacionados con la historia.
- [ ] La base de datos guarda y recupera correctamente los datos necesarios.
- [ ] La aplicación muestra validaciones y mensajes de error claros cuando corresponde.
- [ ] El README o la documentación se actualiza si es necesario.
- [ ] La funcionalidad se puede demostrar al profesor con datos de prueba y su tarjeta está en `Done`.
