# Tablero Kanban — VetStock Manager

El tablero se configurará en GitHub Projects con las siguientes columnas:

| Columna | Uso |
|---|---|
| Product Backlog | Historias de usuario que todavía no han sido seleccionadas para el Sprint actual. |
| To Do | Tareas seleccionadas para el Sprint que aún no se han iniciado. |
| In Progress | Tarea que se está desarrollando actualmente. |
| In Review | Tarea terminada pendiente de pruebas y comprobación de la Definition of Done. |
| Done | Tarea terminada que cumple todos los criterios de calidad. |

## Límite WIP

Como el proyecto es individual, el límite WIP será de una sola tarea en `In Progress`. Esto ayuda a terminar cada tarea antes de empezar otra.
